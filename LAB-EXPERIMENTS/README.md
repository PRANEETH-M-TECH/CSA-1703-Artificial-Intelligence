## 🚀 Execution Instructions

### 1. Running Python Experiments (`exp-1.py` to `exp-16.py`)
Run any Python experiment using terminal:
```bash
python exp-1.py
python exp-7.py
```

### 2. Running Prolog Experiments (`exp-17.pl` to `exp-30.pl`, `exp-32.pl`, `exp-33.pl`)
Load any Prolog file in SWI-Prolog:
```bash
swipl exp-17.pl
```
Inside SWI-Prolog console, test queries (provided inside comments in each file):
```prolog
?- sum_1_to_n(5, Result).
```
Or copy-paste the code into an online compiler like [SWISH (SWI-Prolog Online)](https://swish.swi-prolog.org/).

### 3. Viewing Web Blog (`exp-31.html`)
Open `exp-31.html` directly in any modern web browser (Chrome, Edge, Firefox).
